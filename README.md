# IGNIVA Website — concept edition

A responsive, static website based on the supplied 47-page November 2026 preliminary pitch deck.

## Run
Open `index.html` in a browser, or serve the folder locally: `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Deploy
Upload this folder's files and `assets/` directory to a static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages or an ordinary web host). No backend is required.

## Prior to public launch
- Confirm authorized use of the pitch deck's architectural concept images.
- Add the official registered entity, contact email, phone, address, privacy policy and consent-based lead capture endpoint.
- Obtain legal/project approval for external publication of preliminary capital and commercial claims.
- Validate land permissions, technical specs, sanctioned power and operator/tenant references; avoid representing draft concepts as commissioned or operational.
- Recheck mobile browser rendering and accessibility with production hosting.

## Source / editorial decisions
The concept follows the pitch deck's two-asset vision: a proposed 5-acre 10 MW data-centre parcel and a separate 5-acre ISLE CLUB district. It intentionally leaves the detailed ₹638 Cr/₹698 Cr investment figures, illustrative returns, and proposed pricing out of the public marketing experience; those belong in reviewed, investor-gated materials. All images are extracted from the user-provided pitch deck. No external email address, contact, certification, tenant contract, construction status or groundbreaking date has been invented.
